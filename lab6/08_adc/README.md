# 실습 8 — ADS1115 조향: 가변저항(아날로그) → I2C → 서보 (○ 시간 되면 · 과제 필수)

슬라이드 164~167 · HW #2 A-8 · 소요 20분

**목적**: Jetson 에는 ADC 가 없다 → 아날로그는 I2C 버스를 타고 숫자로 들어온다. ADS1115 의 레지스터 두 개(설정 0x01 · 변환 0x00)만으로 16 비트 값을 읽고, "입력(ADC) → 판단(매핑) → 출력(PWM 서보)" 한 사이클을 완성. 선택으로 PWM + RC 필터가 왜 DAC 가 되는지를 같은 ADC 로 확인.

| 파일 | 역할 |
|---|---|
| `ads1115.py` | 최소 드라이버 (smbus2). 단독 실행 시 A0~A3 전압을 1 초마다 출력(자체 시험). `steer.py` · `pwm_dac.py` 가 import |
| `steer.py` | A0 전압(0~3.3 V) → 각도(0~180°) → 핀 18 서보, 20 Hz 갱신. 각도→듀티는 실습 5 `servo.py` 의 캘리브레이션 값을 import |
| `pwm_dac.py` | (선택) 핀 15 PWM 듀티 0→100 % 를 RC 필터(10 kΩ · 10 µF)에 통과 → A1 전압 측정 → 듀티-전압 표 + `pwm_dac.csv` |

## 배선 (전원 끄고) — ADS1115 입력은 3.3 V 를 넘기지 말 것

```
ADS1115  VDD ─ 3.3 V(핀 1) · GND ─ GND · SCL ─ 핀 5 · SDA ─ 핀 3 · ADDR ─ GND (주소 0x48)
가변저항  한쪽 끝 ─ 3.3 V · 다른 끝 ─ GND · 가운데(와이퍼) ─ ADS1115 A0
서보      갈색 ─ GND · 빨강 ─ 5 V(핀 2) · 주황 ─ 핀 18 (실습 5 와 동일)
(선택)    핀 15 ─ 10 kΩ ─┬─ ADS1115 A1        RC 시정수 100 ms
                         └─ 10 µF(+ 쪽) ─ GND  전해 커패시터 극성 주의 (긴 다리 +)
```

## 실행 순서 (이 폴더에서)

```bash
i2cdetect -l                        # ① I2C 버스 목록 — 40 핀 헤더 핀 3/5 는 보통 버스 7 (장비마다 다름 → 기록)
i2cdetect -y 7                      #    0x48 이 보이면 OK (안 보이면 -y 1 등 다른 버스)
python3 ads1115.py                  # ② A0~A3 전압 1 초마다 — 가변저항을 돌려 A0 이 0~3.3 V 로 변하나
python3 steer.py                    # ③ 가변저항 → 서보. 버스가 7 이 아니면 --bus N
python3 pwm_dac.py                  # ④ (선택) 듀티 0→100 % 10 % 간격 → 전압 표 + pwm_dac.csv
```

`servo.py --cal` 로 맞춘 `DUTY_0` · `DUTY_180` 이 그대로 쓰이므로, 서보 끝점이 이상하면 실습 5 로 돌아가 캘리브레이션.

## 기록 항목 (보고서)

- `i2cdetect -y N` 캡처 (0x48) · 버스 번호
- 가변저항 양끝 · 중간 전압(V) 과 그때 각도(°) 표 — 서보가 실제로 0° · 90° · 180° 근처인지
- `steer.py` 동작 10 초 영상 링크 (핸들 → 바퀴)
- (선택) PWM + RC: 듀티 0~100 % vs 측정 전압 표 + 그래프 · 선형에서 벗어난 원인 추정
- 질문: 16 비트 ADC 가 180° 서보 제어에 의미 있는가 — 각도 분해능 계산 2 문장 (서보의 실제 분해능 · 노이즈 · 갱신 주기와 비교)

## 막히면

| 증상 | 확인 |
|---|---|
| `i2cdetect` 에 0x48 없음 | SDA/SCL 바뀜(핀 3 = SDA · 핀 5 = SCL) · VDD · ADDR → GND · 다른 버스 번호 |
| `Remote I/O error` | 버스 번호 틀림 → `--bus N` · 배선 접촉 |
| `No module named 'smbus2'` | `bash ../setup_lab6.sh` 또는 `pip3 install smbus2` |
| 전압이 3.3 V 근처에서 멈춤 / 0 에서 멈춤 | 가변저항 양끝이 3.3 V · GND 에 각각 붙었는지, 와이퍼가 A0 인지 |
| 서보가 떨리거나 끝에서 버징 | 실습 5 캘리브레이션 값 · 전압 노이즈(평균 몇 번 내기) |
| `pwm_dac.py` 전압이 안 올라감 | 10 µF 극성 · 핀 15 PWM 활성화(`../pins.py`) · 20 kHz 가 안 되면 `--freq 2000` |
