수업: **2026-10-06(화)** · 대상: 교수님 또는 조장이 **Jetson 1대마다** 실행 · 코드 폴더: `lab6/` (준비 스크립트는 `lab6/` 바로 아래, 실습 코드는 `01_led/` … `09_lamp/` 하위 폴더 — 실습 번호 = 폴더 번호)

## A. 수업 전 — Jetson 1대당 (약 12분)

| ☐ | 순서 | 작업 | 명령 / 방법 | 소요 |
|---|---|---|---|---|
| ☐ | 1 | 코드 배포 | 노트북에서 `scp -r lab6/ user@192.168.55.1:~/` (USB-C 접속 시 주소 192.168.55.1, 또는 USB 메모리) | 1분 |
| ☐ | 2 | 패키지 · 권한 | `ssh user@192.168.55.1` → `bash ~/lab6/setup_lab6.sh` — JetPack 버전 출력, `gpiod python3-libgpiod i2c-tools python3-smbus2 stress-ng` 설치, Jetson.GPIO 확인, gpio·i2c 그룹과 udev 규칙, ✓/✗ 요약 | 3~5분 (네트워크) |
| ☐ | 3 | PWM 핀 활성화 | `sudo /opt/nvidia/jetson-io/jetson-io.py` → Configure Jetson 40pin Header → Configure header pins manually → **pwm (13·15·18)** 체크 → Save pin changes → Save and reboot | 1분 + 재부팅 2분 |
| ☐ | 4 | 핀 점검 | 재부팅 후 재로그인 → `bash ~/lab6/pincheck.sh` — 출력 핀 5개를 1초씩 HIGH(LED 하나를 옮겨 가며), 입력 핀 3개 값, PWM 100 ms 수용 여부 · pwmchip 번호 · I2C 버스 번호 출력 | 3분 |
| ☐ | 5 | 결과 반영 | 아래 "Jetson별 기록표"에 적고, 핀 배정표 슬라이드(24번)에 반영. 안 움직이는 핀은 예비 핀(32·33·35·36·37·38·40)으로 교체 후 `lab6/pins.py` 수정 | — |

### 단계별 확인 (끝났다는 증거)

| 단계 | 확인 명령 | 정상 결과 |
|---|---|---|
| 2 | `bash ~/lab6/setup_lab6.sh` 마지막 표 | ✗ 없음 (PWM 만 △ 일 수 있음) |
| 2 | `groups` (재로그인 후) | `gpio` · `i2c` 포함 |
| 3 | `ls /sys/class/pwm` (재부팅 후) | `pwmchip0 pwmchip1 pwmchip2` 3개 (번호는 장비마다 다름) |
| 3 | `python3 ~/lab6/pins.py` | 핀 13·15·18 이 각각 pwmchip 에 대응 |
| 4 | `bash ~/lab6/pincheck.sh` 마지막 요약 | FAIL 없음. PWM 줄에 `10 Hz OK` (안 되는 장비는 `50 Hz OK` 와 이유 기록) |

### 자주 막히는 곳
| 증상 | 대처 |
|---|---|
| `apt-get` 이 안 됨 (인터넷 없음) | 아래 B 의 (a) 노트북 인터넷 공유 또는 (b) `lab6/deb/` 사용 |
| `Permission denied` | 재로그인(또는 재부팅) 전일 수 있음 → `groups` 확인. 급하면 `bash pincheck.sh --sudo` |
| `pwmchip` 이 없음 | 3단계를 다시: jetson-io 에서 pwm 이 체크되고 저장·재부팅까지 됐는지 |
| 특정 핀이 HIGH 가 안 나옴 (JetPack 6.2.x 일부 보고) | 예비 핀으로 교체하고 기록 |
| PWM `Invalid argument` (10 Hz) | 정상일 수 있음. 되는 최저 주파수를 기록 → 실습 6 에서 학생이 같은 걸 확인 |

## B. 수업 전이 어렵다면 — 수업 시작 직후 학생이 직접

| ☐ | 시각 | 내용 |
|---|---|---|
| ☐ | 0~5분 | 조별 접속 → `bash lab6/setup_lab6.sh` 실행 → `jetson-io` 로 PWM 설정 → 재부팅 (PART 1·2 이론 25분 동안 완료) |
| ☐ | PART 3 | `bash lab6/pincheck.sh` 결과 확인. 실습 1 이 곧 출력 핀 점검, 실습 5·6 에서 PWM 확인 |

**전제: Jetson 이 인터넷에 연결돼 있어야 apt 설치가 됨.** 안 되면:
- (a) **노트북 인터넷 공유** (USB-C 로 연결된 노트북의 인터넷을 Jetson 에 공유)
- (b) **`.deb` 미리 받아 두기**: 인터넷이 되는 깨끗한 Jetson **1대**에서 `bash setup_lab6.sh --save-debs` 를 실행하면 `lab6/deb/` 에 `.deb` 가 복사됨 → 그 폴더가 든 `lab6/` 를 배포. 인터넷이 없는 Jetson 에서는 `setup_lab6.sh` 가 `deb/*.deb` 로 자동 설치 시도
  - 꼭 **패키지를 처음 설치하는** Jetson 에서 실행해야 의존 패키지까지 담김 (이미 설치된 Jetson 이면 비어 있음)
